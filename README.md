# 🚀 PowerShell QR-FileServer (Portable & Zero-Waste)

Легковесный, абсолютно "стерильный" HTTP-сервер на PowerShell и Python для мгновенной передачи файлов между ПК и смартфоном через локальную сеть. 

Проект спроектирован по принципу **Zero-Waste (Ноль мусора)**: он работает на 100% в оперативной памяти, не создает временных файлов на жестком диске и мгновенно освобождает ресурсы после закрытия. Идеально подходит для слабого железа и геймеров, где каждый мегабайт ОЗУ и такт процессора на счету.

---

## 🌟 Главные фичи архитектуры

* 🧠 **RAM-Only генерация:** Python-код для создания QR передается строкой напрямую в ОЗУ через ключ `-c`. Никаких временных `.py` файлов в `AppData\Local\Temp`.
* 📡 **Умный сетевой фильтр:** Скрипт автоматически игнорирует виртуальные адаптеры (VirtualBox, VMware), петли (Loopback) и «мертвые» авто-IP адреса Windows (`169.254.*`). Он всегда находит правильный рабочий IP.
* 🛡 **Изолированный запуск:** Использование флага `-NoProfile` предотвращает загрузку глобальных профилей PowerShell, ускоряя старт и гарантируя портативность на любом ПК.
* 🎮 **Anti-Lag & No-GUI:** Вывод QR-кода прямо в консоль символами полублоков. Видеокарта не тратит память на отрисовку графических окон, что исключает фризы в играх при фоновом обмене файлами.

## 📂 Структура проекта

Для удобства использования в портативном режиме структура папок разделена на «Основную» и «Скрытую легаси»:

* `► ЗАПУСК_СЕРВЕРА.bat` — Главный лаунчер. Мгновенно поднимает основной сервер в одно кликабельное окно. Благодаря спецсимволу всегда висит в самом верху папки.
* `server.ps1` — Актуальный скрипт с компактным ASCII-QR кодом в консоли.
* `запуск_legacy.bat` — Лаунчер старой версии (автоматически отсортирован вниз папки, чтобы не мозолить глаза).
* `server_classic.ps1` — Легаси-версия, которая генерирует QR в виде картинки `qr.png`, автоматически удаляя её с диска через 0.5 секунды после открытия в просмотрщике.
