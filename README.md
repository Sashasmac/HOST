# 🚀 PowerShell QR-FileServer

Легковесный HTTP-сервер на PowerShell для мгновенной передачи файлов между ПК и смартфоном через локальную сеть. Идеально подходит для "слабого" железа, где каждое открытое окно на счету.

## 🌟 Обновление: ASCII-QR (v2.0)
В новой версии мы отказались от открытия графических окон для отображения QR-кода. Теперь код генерируется **прямо в консоли**.

**Что это дает:**
* 📉 **Экономия ресурсов:** Видеокарта (например, GT 720M) не тратит память на отрисовку GUI.
* ⚡ **Скорость:** Никаких лишних процессов, только чистый текст.
* 🎮 **Anti-Lag:** Идеально для тех, кто играет в облачные игры (Metro Exodus и др.) и не хочет ловить фризы при `Win+Tab`.

## 📂 Структура репозитория
* `server.ps1` — Актуальная версия с компактным QR-кодом в консоли.
* `legacy/` — Папка со старой версией (Legacy), которая генерирует QR в виде отдельного PNG-файла.
